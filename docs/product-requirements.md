# 제품 요구사항 정의서

## 1. 제품의 중심

지금 실제로 밤인 다른 장소의 하늘을 함께 바라보는 감각을 제공한다. Stellarium Web Engine으로 현재 위치·시각에 맞는 하늘을 계산하고, 기상 반영을 통해 장소의 현재 분위기를 더하는 방안을 검토한다.

시간은 사용자가 조작하는 콘텐츠가 아니다. 실제 시간에 따라 별이 천천히 움직이는 경험을 유지한다. 현장 카메라 영상은 아니며 기상 효과도 데이터에 기반한 근사 표현이다.

## 2. 위치 선택 흐름

1. 페이지 첫 진입에서 이번 탭에서 사용할 닉네임을 정한다.
2. 세계지도를 연다. 현재 UTC와 밤 영역, 현재 관측 중인 사용자의 근사 위치 핀이 보인다.
3. 확대·축소, 드래그/스와이프로 장소를 찾거나 도시·장소를 검색한다.
4. 검색 결과를 고르면 해당 지역이 화면에 들어오도록 이동·확대한다.
5. 사용자가 지도를 최종 클릭/tap하여 정확한 관측 좌표를 확정한다.
6. 카드에 읽기 전용 위도·경도와 현재 진입 가능 여부를 표시한다.
7. 밤 조건을 통과한 경우 `이곳의 밤하늘 보기`로 진입한다. 버튼을 누르는 시점에 다시 판정한다.
8. 현재 시각의 하늘을 감상하고, 시선을 돌리거나 확대하며 별자리 표시를 조절한다. 이때 다른 사용자의 지도에 근사 관측 위치가 표시된다.
9. 다른 장소를 보고 싶으면 지도로 돌아가 다시 탐색·클릭한다. 지도 복귀 시 관측 중 상태는 종료된다.

검색 결과의 중심 좌표와 최종 클릭 좌표를 구분한다. 검색 결과만 선택하거나 지도만 움직인 상태에서는 하늘 진입을 허용하지 않는다. 검색으로 새 지역을 선택하면 이전 확정 좌표를 해제해 실수로 이전 위치에 진입하지 않게 한다.

## 3. 밤 진입 정책

낮인 장소는 지도에서 탐색하고 클릭할 수 있지만 하늘 화면은 열 수 없다. 클릭 좌표는 카드의 차단 이유를 보여주는 데 사용한다.

기본 기준은 사용자가 확정한 태양 중심의 기하 고도 `h <= -18°`다. 기본 설정에서는 시민·항해·천문박명이 모두 진입 불가이며 천문학적으로 완전히 어두운 밤만 허용한다. 등호는 제품 경계 규약이다.

경계값은 백엔드 환경 변수 `NIGHT_ALTITUDE_THRESHOLD_DEG`에서 읽고 기본값을 `-18`로 둔다. 공개 설정 API가 반환한 하나의 값을 지도 음영·선택 카드·진입·관측 종료에 사용하며 화면별로 숫자를 반복하지 않는다. 잘못된 설정은 서버 시작 단계에서 거부하고, 설정을 불러오지 못하면 관측 진입을 차단한다.

- 지도 안내는 최대 60초마다 갱신한다.
- 클릭, 진입 버튼, 엔진 준비 완료, 탭 복귀에는 현재 UTC로 즉시 재판정한다.
- 활성 하늘에서는 매초 재판정한다. 기준을 넘으면 하늘을 가리고 렌더링을 중단한 종료 안내와 `다른 밤 지역 찾기`를 표시한다.
- 판정 실패는 진입 불가다. 날씨 API의 낮/밤 필드나 지도 음영만으로 허용하지 않는다.
- 극야는 기준을 충족하면 허용하고 백야는 차단한다. 일반 평면지도의 표시 범위 밖 극점은 MVP에서 선택하지 않는다.

## 4. MVP 필수 범위

- 일반 세계지도 형태의 이동·줌, 모바일 스와이프·핀치
- 도시·장소 검색과 검색 결과 선택 시 지도 이동·확대
- 최종 지도 클릭/tap으로 관측 좌표 확정, 좌표 읽기 전용 표시
- 현재 태양 고도에 따른 진입 차단과 관측 중 조건 종료
- 현재 UTC만 반영하는 하늘, 자동 천체 추적 해제
- 초기 시선 북쪽 0°·고도 45°, FOV 70°, 제품 줌 범위 20~120°
- 하늘 둘러보기, 확대·축소, 초기 시선 복구
- 별자리 선·기본 이름 독립 토글
- 첫 진입 닉네임 세션, 관측 중인 사용자의 근사 위치 핀과 겹침 집계
- 로딩·차단·오류·탭 복귀, 반응형·키보드 대체 조작

세계지도 검색은 로컬 주요 도시 목록만으로 제한하지 않는다. 구체적인 장소 검색 범위·한국어 품질·비용은 제공자 선정에서 검증한다. Google Maps 같은 조작 경험을 요구한 것이며 Google 유료 API 계약을 확정한 것은 아니다.

## 5. 기상 반영 제안 범위

최신 운량·날씨 상태·기상 기준 시각을 보여주고, 운량에 따른 구름과 별 가림을 추가하는 안을 제안한다. 기상 요약과 구름 화면 합성은 각각 검증한다. 실제 채택 범위는 [기상 반영 검토안](./weather-integration.md)을 따른다.

맑을 때도 항상 장식 구름을 띄우거나 흐린 날의 운량을 임의로 낮추지 않는다. 흐리거나 비가 오는 밤도 진입은 허용한다. 기상 정보가 없으면 맑음으로 가정하지 않고 `기상 미반영` 상태로 기본 하늘을 제공한다.

## 6. 제외·후속 기능

배속, 시간 일시정지, 날짜 선택, 과거/미래 이동, 다음 밤 시각으로 이동, 고정 과거 시각 공유는 제품 방향에서 제외한다. 위도·경도 직접 입력도 기본 사용자 흐름에 넣지 않는다.

후속 후보는 별자리 한글 툴팁·상세 정보, 현재 위치로 지도 이동 후 클릭, 선택 위치 공유 후 현재 밤 재판정, 실제 지형·광공해다. 회원가입·소셜 로그인·AR은 MVP 제외다.

같은 지역의 관측자 채팅도 후속 후보로만 둔다. 국가·도시·행정구역·좌표 격자 중 채팅방 기준, 이동 시 입·퇴장, 신고·차단·도배 제한, 메시지 보관을 별도 기획하기 전에는 채팅 UI·API·메시지 저장소를 만들지 않는다. 현재 관측자 핀의 격자를 채팅방 기준으로 자동 확정하지 않는다.

## 8. 비기능 목표

지도 UI 준비 3초, 하늘 필수 데이터 준비 10초, 데스크톱 60fps·모바일 30fps를 미측정 목표로 둔다. 데이터 크기·제공자·실기기 조건으로 향후 확정한다. 상세 조건은 테스트 계획을 따른다.

시간은 UTC epoch ms, 좌표는 WGS84 도 단위로 관리한다. 정확한 클릭 위치·닉네임·관측 이력은 영구 저장하지 않는다. 관측 중에는 닉네임과 약 0.25° 격자로 변환한 근사 관측 위치가 다른 사용자에게 공개된다는 사실과 지도·검색·기상 제공자에 필요한 요청이 전달된다는 사실을 고지한다. 숨긴 탭은 렌더링과 presence heartbeat를 줄이고 복귀 시 과거 화면을 이어 보여주지 않는다.

## 9. 메인 지도 밝기와 하늘 배경

| ID    | 요구사항             | 완료 기준                                                                                                 |
| ----- | -------------------- | --------------------------------------------------------------------------------------------------------- |
| FR-13 | 낮/밤 지도 표현      | 낮 중심부는 밝게, 박명까지 부드럽게 전환. 설정된 밤 기준 이하의 관측 가능 영역은 모두 동일 밤 색상·투명도 |
| FR-14 | 자연스러운 하늘 배경 | 대기 켜짐, 균일한 검정 강제 없음, 현재 천체·대기 표현 유지                                                |

한국이 정오 부근이면 한국을 포함한 낮 영역을 손전등처럼 넓고 부드럽게 밝히는 느낌을 준다. 빛의 위치는 현재 태양 방향에 따라 이동한다. 사용자가 클릭한 곳을 빛 중심으로 바꾸지 않는다.

관측 가능 영역의 상태색은 한 가지다. 같은 밤 안에서 태양 고도·달·날씨에 따라 지도 음영을 더 바꾸지 않는다. 지형·도로·지명 등 원래 지도 정보는 남기며 상태 음영의 색과 투명도를 통일한다. 범례는 낮·박명·밤하늘 보기 가능을 구분하고 관측자 핀은 음영보다 위에 표시한다.

하늘 뷰어의 밝기는 지도 상태색과 독립적이다. 선택 위치의 현재 하늘을 대기 켜짐 상태로 표현하고, 기본 -18° 이하에서도 달이나 대기·방향에 따른 차이를 없애지 않는다.
