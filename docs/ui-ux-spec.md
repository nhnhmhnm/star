# UI·UX 명세서

현재는 화면 기획만 진행한다. 핵심 경험은 ‘지도에서 지금 밤인 곳을 클릭해 그곳의 현재 하늘 감상’이다.

## 1. 세계지도

일반적인 Google Maps처럼 도로·도시·국가를 읽을 수 있는 평면 세계지도를 사용한다. 별 관측 화면의 어두운 테마를 지도 전체에 강요하지 않는다. 지도 위에 밤 안내 음영을 얹되 지명과 도로를 가리지 않도록 한다.

| 조작 | 동작 |
|---|---|
| PC 드래그 | 상하좌우 지도 이동 |
| 모바일 한 손가락 스와이프 | 지도 이동, 손을 뗄 때 위치 선택하지 않음 |
| 휠·핀치·+/− 버튼 | 확대·축소 |
| 검색 결과 선택 | 해당 장소의 범위에 맞게 이동·확대, 관측 좌표 미확정 |
| 지도 한 번 클릭/tap | 그 지점의 위도·경도 확정과 밤 판정 |
| 키보드 대체 | 방향키/버튼으로 중심 이동 후 `이 지점 선택` 명시적 활성화 |

검색창은 도시·장소명을 받는다. 국가·행정구역을 함께 보여 동명 지명을 구분한다. 결과 범위가 있으면 화면에 맞추고, 점만 있으면 제공자·장소 유형별 적절한 줌으로 이동한다. 이동 애니메이션 중 클릭은 받지 않는다.

새 검색 결과를 선택하면 이전 관측 마커·진입 가능 상태를 해제하고 `지도에서 보고 싶은 지점을 눌러 주세요`를 표시한다. 단순 지도 이동·줌만으로 기존 클릭 좌표를 바꾸지는 않는다. 마커가 화면 밖으로 나가면 `선택 지점으로 이동`을 제공한다.

## 2. 선택 카드

- 제목: `선택한 위치`, 조회된 지역명이 있으면 보조 표시
- 위도·경도: 읽기 전용, 북위/동경 양수 규칙
- 현재 상태: `관측 가능` / `아직 밝음` / `낮` / `확인 불가`
- 실제 박명 단계는 보조 설명으로 구분
- 버튼: `이곳의 밤하늘 보기` — 밤 조건 충족 시만 활성

검색 장소명을 임의로 클릭한 주변 지점의 정확한 이름으로 쓰지 않는다. 밤 기준은 사용자가 확정한 태양 중심의 기하 고도 -18° 이하를 따른다.

낮 클릭 시 `현재 낮인 지역입니다. 지도에서 밤인 곳을 선택해 주세요.`
박명 중 기준 미달 시 `아직 하늘이 밝습니다. 더 어두운 지역을 선택해 주세요.`

불허 위치도 클릭 좌표와 이유는 표시한다. 검색 결과나 읽기 전용 좌표를 통해 하늘 진입을 우회하지 못하게 한다.

## 3. 입력 충돌·지도 오류

드래그·스와이프·핀치·더블클릭 확대를 최종 단일 클릭과 구분한다. 모바일은 손가락을 뗀 뒤 지도 이동 제스처가 아니었을 때만 확정한다. 검색 목록·줌 버튼·출처 영역 클릭은 관측 위치 선택으로 전달하지 않는다.

검색 실패는 재시도와 수동 지도 탐색을 제공한다. 지도 바탕을 불러오지 못하면 새 지점 확정을 막고 재시도한다. 좌표 입력으로 흐름을 우회하지 않는다. 지도 출처를 패널 아래에 가리지 않는다.

## 4. 밤하늘 화면

배경은 어두운 하늘이며 Stellarium의 별과 별자리 기본 표시를 사용한다.

- 좌상단: 지도로 돌아가기, 선택 위치·좌표
- 상단: 큰 현재 시각·날짜·시간대와 `현재 하늘` 상태
- 우상단: 별자리 선·이름 토글
- 하단: 방위·고도, 확대·축소, 초기 시선
- 기상 채택 시: 날씨·운량·기상 기준 시각, 지연 또는 미반영 안내

재생/정지, 속도, 날짜 선택, 시간 이동, 실시간 복귀 버튼을 두지 않는다. 처음부터 현재 시각만 존재한다.

초기 시선은 북쪽 0°·고도 45°·FOV 70°다. 하늘 드래그로 방향을 바꾸고 휠·핀치·버튼으로 20~120°를 조절한다. 초기 시선 버튼은 방향과 FOV만 복구한다. 자동 천체 추적은 해제해 실제 시간에 따른 느린 이동이 보이게 한다.

## 5. 감상 중 밤 조건 종료

활성 화면에서 매초 확인하고 더 이상 밤 조건을 충족하지 않으면 하늘을 완전히 가린 뒤 렌더링을 중단한다. 어두웠던 마지막 화면을 계속 보여주지 않는다.

`이곳은 이제 하늘이 밝아졌습니다. 다른 밤 지역을 찾아보세요.`

`다른 밤 지역 찾기` 버튼으로 지도를 연다. 사용자가 읽기 전에 갑자기 다른 장소로 이동시키지 않는다. 현재 시각은 계속 흐르며, 미래 밤 시각으로 건너뛰는 기능은 없다. 로딩 중이나 탭을 비운 동안 경계를 넘었어도 같은 안내를 적용한다.

## 6. 기상 표현 제안

운량에 따라 구름이 별을 일부 가리게 하되, 실제 구름 위치를 재현한다고 표현하지 않는다. 맑은 날은 구름을 거의 표시하지 않는다. 흐린 날에는 별이 많이 가려질 수 있고 강수 여부는 우선 안내로 보여준다.

기상 데이터가 없으면 `기상 미반영`, 오래되면 `기상 정보 갱신 지연`을 표시한다. 자료 기준 시각과 조회 시각을 혼동하지 않는다. 상세 정책은 [기상 반영 검토안](./weather-integration.md)을 따른다.

## 7. 접근성·반응형·후속

키보드 사용자는 지도 중심을 이동하고 명시적으로 지점을 선택한다. 이는 검색 자동 확정이나 직접 좌표 입력이 아니라 최종 지도 선택의 대체 조작이다. 버튼 터치 영역은 44×44 CSS px를 목표로 하고 상태는 텍스트와 함께 표시한다.

모바일은 검색창과 선택 카드를 접어 지도 탐색 공간을 확보한다. 뷰어에서는 위치·현재 시각·뒤로가기를 항상 표시한다. 구름 이동의 동작 줄이기는 가능하나 천문 시계는 멈추지 않는다.

별자리 한글 hover/tap·상세 설명은 후속 기능이다. 기본 이름 표시와 필수 감상 기능을 hover에 의존시키지 않는다.

## 8. 지도 낮/밤 색상 — 최종 기준

- 낮 중심부: 넓고 부드러운 밝은 영역. 하얗게 날려 지명이 안 보이는 표현은 피한다.
- 아침·저녁·박명: 태양 고도에 따라 밝기를 점진적으로 낮춘다.
- **h <= -18°: 관측 가능한 모든 곳에 동일한 남색 계열 상태색과 동일 투명도. 밤 내부의 밝기 그라데이션 없음.**
- 최종 밤 색상은 지명·도로가 읽히도록 정한다. 초기 검토값은 남색 음영 25~35%, 상한 40%이며 실제 바탕지도에서 조정할 디자인 제안이다.
- -18° 경계는 동일 밤 색상으로 수렴하게 하되 범례·선택 카드로 진입 가능 여부를 명확히 한다.
- 마커·검색 UI·선택 카드·출처는 음영 위에 두거나 별도로 보존한다.
- 같은 밤 색상이란 관측 가능 상태 레이어의 색·투명도를 뜻한다. 바다·육지·도로를 모두 지우고 단색 화면으로 덮지 않는다.
- 지도 pan/zoom에도 색 영역은 지리 위치에 고정된다. 날짜변경선과 반복된 세계지도에도 동일하게 이어진다.

하늘 뷰어는 대기를 기본 켜고 균일한 검정으로 덮지 않는다. 지도에서 동일한 밤 색인 두 장소라도 뷰어 배경은 달·대기와 시선에 따라 달라질 수 있다.
